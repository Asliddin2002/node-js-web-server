# 🚀 Node.js Web Server (Express + HTML + CSS + JSON Storage)

A small but feature-rich Node.js + Express web server that serves static HTML pages, CSS, images, and exposes a simple REST API using a JSON file as a lightweight database.
Includes middleware setup (CORS, error handler, request logger) and custom pages (Home, Cat, 404) with clean UI.

## ✨ Features

### 🔧 Web Server

- Serves static HTML, CSS, images, and other public assets

- Custom pages:

  - 🏠 Home Page

  - 🐱 Cat Page

  - ❌ 404 Page (with animations)

### 🧩 Express Middleware

- CORS enabled

- Log tracking

- Static file serving

### 🗃️ API Features

- Employee CRUD API (/api/employees)

- Express Router structure

- JSON-based lightweight storage (acts as a tiny DB)

- No external database needed

## 📦 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Asliddin2002/node-js-web-server.git
```

### 2. Navigate into the folder

```bash
cd node-js-web-server
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the development server

```bash
npm run dev
```

## 🛠 Tech Stack

- Node.js

- Express.js

- Vanilla HTML / CSS
